# Дизайн и интерфейс FamilyCloud: ревью и ТЗ

Документ уточняет внешний вид и поведение экранов из `SPEC.md`, раздел 3. Новых функций он не добавляет.
Пункты с пометкой **«расширяет SPEC»** делать только после согласия пользователя и правки `SPEC.md`.

Стек не меняется: Compose, Material 3, Navigation Compose, Coil, Media3, `material-icons-extended`.
Новые библиотеки не нужны.

---

## Часть 1. Ревью текущего интерфейса

Ревью по коду (`ui/Screens.kt`, `ui/AppNav.kt`, `ui/AppUpdate.kt`, `res/`). На устройстве экраны не смотрелись.

### Общая оценка

Функционально экраны полные, но выглядят как черновик: стандартные компоненты без иерархии, все тексты
одного веса, предупреждения обычным текстом, нет пустых состояний и карточек. Есть три ошибки навигации,
которые мешают пользоваться приложением сильнее, чем внешний вид.

### P0. Ошибки навигации и потери данных

| # | Где | Проблема |
|---|---|---|
| N1 | Файлы | Системная кнопка или жест «Назад» во вложенной папке **закрывает приложение**: `BackHandler` нет, а экран файлов — корень навигации. Стрелка в шапке работает, жест — нет. |
| N2 | Файлы, мультивыбор | «Назад» в режиме выбора тоже закрывает приложение вместо снятия выделения. |
| N3 | Подключение из файлов | Экран открывается без стрелки «Назад». После «Проверить и сохранить» создаётся **второй** экран файлов поверх первого: `navigate("browser") { popUpTo("connection") }` не убирает исходный. «Назад» возвращает в старый список. |
| N4 | Синхронизация | «Убрать альбом» удаляет пару сразу, без подтверждения. История выгрузок пары теряется. |
| N5 | Выбор папки | Экран выглядит как обычный список файлов: заголовок не говорит «Куда переместить», пользователь не понимает, что он в режиме выбора. |

### P1. Удобство

**Файлы**
- В шапке четыре иконки (сортировка, обновить, синхронизация, настройки). «Обновить» дублирует pull-to-refresh.
- Две FAB друг над другом (маленькая «загрузить», большая «папка») без подписей: назначение не очевидно.
- Хлебные крошки дублируют заголовок; «Корень» — техническое слово.
- Ошибка показывается дважды: строкой на экране и snackbar одновременно (`message` и `failure`).
- Пустая папка — одна строка «Папка пуста» без иконки и без подсказки, что делать.
- Загрузка файлов в папку видна только в уведомлении: на экране ничего не меняется, пока не обновишь список.
- Мультивыбор отмечается только фоном строки: нет галочки на иконке и нет «Выбрать все».
- Галочка в меню сортировки — символ `✓` текстом, а не иконка.
- Скачивание показывает тонкую полоску без имени файла и процента.

**Подключение**
- Кнопка «Проверить обновление» стоит между заголовком и полями — это главный экран входа, обновление здесь отвлекает.
- Подсказка про HTTP показывается всегда, даже когда флажок выключен.
- «Способ входа: Basic (определён автоматически)» и «Проверяется адрес» — отладочные тексты в основном потоке.
- Ошибка входа — длинный красный абзац без иконки.

**Синхронизация**
- «Синхронизировать сейчас» — та же иконка `Sync`, что и вход в синхронизацию на экране файлов. Без подписи действие неочевидно.
- «Добавить альбом» — иконка `+` в шапке, а не FAB.
- Пара — колонка из шести переключателей подряд без группировки и без карточки. Две пары уже не помещаются на экран.
- Предупреждения (частичный доступ, геометки, батарея, разрешения) — обычный текст подряд; важное и второстепенное не различаются.
- Пока идёт синхронизация, экран ничего не показывает: прогресс только в уведомлении.
- Ошибка пары без кнопки «Повторить».
- Выбор альбома — диалог со списком текстовых кнопок, без превью и числа файлов.

**Просмотр фото и видео**
- Фото на фоне темы с постоянной шапкой, а не на чёрном с полноэкранным режимом.
- Нет счётчика «3 из 20», нет действий «Скачать» и «Удалить» прямо из просмотра.
- Пока фото грузится, пустой экран без индикатора; ошибка загрузки не показывается.
- Видео внутри Scaffold с шапкой, без полноэкранного режима и без ландшафта на весь экран.

**Обновление**
- Диалог с длинными текстами. Прогресс в КиБ («12345 / 67890 КиБ») вместо МБ и процента.

### P2. Внешний вид

- Нет своей цветовой схемы: без Dynamic Color (Android 8–11) используются стандартные фиолетовые `lightColorScheme()`/`darkColorScheme()`, хотя иконка синяя `#1565C0`.
- `themes.xml` наследует `android:Theme.Material.NoActionBar`: при запуске мелькает системный фон, а не цвет приложения.
- Иконка лаунчера — обычный vector, а не adaptive icon: на многих лаунчерах будет квадрат в белом круге.
- Экран загрузки (`BootScreen`) — слово «FamilyCloud» по центру обычным шрифтом.
- Иконки файлов одного цвета; тип файла различается только формой.
- Нет единых отступов и размеров: `12.dp`, `16.dp`, `24.dp`, `88.dp` разбросаны по коду.
- `Screens.kt` — 1000 строк: экраны не разнесены по пакетам `ui/browser`, `ui/sync`, `ui/settings` (как требует `SPEC.md` раздел 5).

## Часть 2. ТЗ по дизайну

### 2.1 Принципы

1. **Как в Google Диске, но проще.** Главный экран — файлы, всё остальное в один шаг от него.
2. **Одно главное действие на экране** — оно в FAB. Остальное в шапке или меню.
3. **Состояние всегда видно**: загрузка, пустота, ошибка, идущая выгрузка. Никаких пустых белых экранов.
4. **Системное «Назад» ведёт себя предсказуемо**: снимает выделение, поднимается на папку вверх, закрывает экран.
5. **Только токены темы**: цвета из `MaterialTheme.colorScheme`, шрифты из `typography`, формы из `shapes`. Никаких `Color(0x…)` и `fontSize` в экранах.

### 2.2 Тема и токены

**Цвет.**
- На Android 12+ — Dynamic Color (уже есть), оставить.
- На Android 8–11 — своя схема из seed-цвета `#1565C0` (синий иконки). Сгенерировать светлую и тёмную схему в Material Theme Builder и положить в `ui/theme/Color.kt`. Фиолетовых стандартных цветов в приложении быть не должно.
- Семантика: ошибка — `error`/`errorContainer`; предупреждение — `tertiaryContainer`; успех — `primaryContainer`. Отдельных «зелёных» и «жёлтых» цветов не вводить.

**Типографика.** Стандартная шкала M3. Соответствие:

| Элемент | Стиль |
|---|---|
| Заголовок экрана | `titleLarge` (в TopAppBar по умолчанию) |
| Заголовок карточки, имя альбома | `titleMedium` |
| Имя файла | `bodyLarge` |
| Размер и дата файла, подписи | `bodyMedium`, цвет `onSurfaceVariant` |
| Хлебные крошки, чипы | `labelLarge` |
| Заголовок пустого состояния | `titleMedium`, текст — `bodyMedium` |

**Отступы.** Завести `ui/theme/Dimens.kt`:

```kotlin
object Dimens {
    val xs = 4.dp
    val s = 8.dp
    val m = 12.dp
    val l = 16.dp
    val xl = 24.dp
    val listIcon = 40.dp
    val fabClearance = 88.dp
}
```

Экранные поля — `l` (16 dp) по горизонтали. Между карточками — `m`. Внутри карточки — `l`.

**Формы.** Карточки — `shapes.medium`, превью в списке — `shapes.small`, диалоги и нижние листы — по умолчанию M3.

**Запуск.** `themes.xml`: родитель с фоном приложения (`android:windowBackground` из цвета поверхности, отдельно для `values-night`), чтобы при старте не мелькал системный фон. Splash Screen API не подключать (новая зависимость).

**Иконка.** Adaptive icon: `mipmap-anydpi-v26/ic_launcher.xml` с `background` (сплошной `#1565C0`) и `foreground` (белое облако в безопасной зоне 66 dp), плюс `monochrome` для тематических иконок Android 13. Иконка уведомления — уже есть, оставить.

### 2.3 Навигация

```
Файлы (корень) ──┬── Синхронизация
                 ├── Настройки подключения
                 ├── Просмотр фото / Видео
                 └── Выбор папки (для «Переместить», «Копировать», пары)
```

- Экраны «Файлы» и «Синхронизация» — главные. На телефоне — `NavigationBar` снизу с двумя вкладками «Файлы» и «Синхронизация». При переключении вкладок состояние сохраняется (`saveState`/`restoreState`), папка не сбрасывается в корень.
  *Если пользователь против нижней панели — оставить вход в синхронизацию иконкой в шапке, но с подписью в меню.*
- Подключение — из шапки файлов через меню «⋮ → Подключение». Экран со стрелкой «Назад». После успешной проверки — `popBackStack()` к файлам и обновление списка, **без** создания нового экрана файлов. При первом запуске (настроек нет) — стартовый экран без стрелки.
- **BackHandler на экране файлов**, по порядку: снять выделение → подняться на уровень вверх → стандартное поведение (выход). Отключён, когда путь — корень и выделения нет.
- Выбор папки — отдельный режим с понятной шапкой (см. 2.6).
- Переходы между экранами — стандартные анимации Navigation Compose, без своих.

### 2.4 Общие компоненты

Вынести в `ui/components/`:

**`EmptyState(icon, title, text, action?)`** — по центру: иконка 64 dp цвета `onSurfaceVariant`, заголовок, одна строка пояснения, необязательная кнопка.

| Где | Иконка | Заголовок | Текст | Кнопка |
|---|---|---|---|---|
| Пустая папка | `FolderOpen` | Папка пуста | Загрузите файлы или создайте папку | — (FAB рядом) |
| Нет пар синхронизации | `PhotoLibrary` | Альбомы не выбраны | Выберите альбом, и новые фото будут выгружаться сами | Добавить альбом |
| Нет альбомов на телефоне | `NoPhotography` | Альбомы не найдены | Разрешите доступ к фото и видео | Открыть настройки |

**`ErrorState(text, onRetry)`** — вместо списка, если список не загрузился: иконка `CloudOff`, текст ошибки, кнопка «Повторить» (`FilledTonalButton`). Если список уже был на экране и обновление не удалось — список остаётся, ошибка уходит в snackbar с действием «Повторить». **Одна ошибка — одно место показа**, без дубля.

**`Notice(tone, text, action?)`** — плашка предупреждения: карточка `tertiaryContainer` (предупреждение) или `errorContainer` (ошибка), иконка слева, текст, кнопка справа или снизу. Закрывается крестиком, если предупреждение не критичное (геометки, батарея); закрытие запоминается в DataStore.

**`LoadingList`** — при первой загрузке папки 8 строк-заглушек (серые прямоугольники `surfaceVariant` вместо иконки, имени и даты), а не пустой экран. При обновлении — только индикатор pull-to-refresh.

**`TransferBar`** — компактная полоса под шапкой файлов во время загрузки или скачивания: иконка направления, «Загрузка 3 из 7 · IMG_2041.jpg», линейный прогресс с процентом текущего файла, кнопка «Отмена». Нажатие по полосе ничего не делает. Источник — тот же прогресс, что в уведомлении (`TransferProgress`, WorkInfo).

**Иконка файла `FileGlyph`** — цветной круг 40 dp с иконкой, цвет по типу:

| Тип | Иконка | Фон / цвет иконки |
|---|---|---|
| Папка | `Folder` | `primaryContainer` / `onPrimaryContainer` |
| Фото | превью `shapes.small` 40 dp; пока грузится — `Image` | `secondaryContainer` |
| Видео | `Movie`, на превью — маленький значок ▶ | `tertiaryContainer` |
| PDF, документы | `Description` | `surfaceVariant` |
| Архив | `FolderZip` | `surfaceVariant` |
| Аудио | `AudioFile` | `surfaceVariant` |
| Прочее | `InsertDriveFile` | `surfaceVariant` |

Превью видео не делать (сервер их не отдаёт, кадр из потока — лишняя нагрузка).

### 2.5 Экран «Файлы»

**Шапка (обычный режим).**
- В корне: заголовок «Файлы». Во вложенной папке: имя папки и стрелка «Назад».
- Действия: «Сортировка» (иконка), «⋮» с пунктами «Обновить», «Подключение», «Проверить обновление».
- Без отдельных иконок «Обновить» и «Синхронизация» (синхронизация — в нижней панели).

**Хлебные крошки** — строка чипов под шапкой, только во вложенных папках. Первый элемент — иконка `Home` вместо слова «Корень». Последний элемент (текущая папка) — не кликабельный, выделен цветом `primary`. При глубокой вложенности крошки прокручиваются горизонтально и автоматически к концу.

**Сортировка** — нижний лист (`ModalBottomSheet`), а не выпадающее меню: три пункта «Имя», «Дата изменения», «Размер» с `RadioButton` и переключатель направления (`SegmentedButton`: «А→Я / Я→А», для даты «Сначала новые / старые», для размера «Сначала большие / маленькие»). Текущая сортировка видна мелкой строкой над списком: «По дате, сначала новые».

**Список.**
- Строка: `FileGlyph`, имя (`bodyLarge`, одна строка с многоточием посередине для длинных имён — расширение видно), под ним «2,4 МБ · 12.11.2026 14:03». Для папок только дата.
- Справа «⋮» с действиями над одним файлом. Действия в меню с иконками.
- Разделителей между строками нет; группы «Папки» и «Файлы» не подписывать.
- Отступ снизу под FAB — `fabClearance`.

**Мультивыбор.**
- Долгое нажатие включает режим; иконка в строке заменяется кругом с галочкой (анимация 150 мс), фон строки — `secondaryContainer`.
- Шапка режима: «×», «Выбрано: 3», действия «Скачать», «Переместить», «Удалить» иконками и «⋮» с «Копировать», «Переименовать» (если выбран один), «Выбрать все».
- «Назад» снимает выделение.
- FAB в режиме выбора скрыт.

**FAB.** Один `ExtendedFloatingActionButton` «+ Добавить», при прокрутке вниз сворачивается в круглую кнопку. Нажатие открывает нижний лист с двумя пунктами: «Загрузить файлы» (`Upload`) и «Создать папку» (`CreateNewFolder`).

**Диалоги.**
- «Новая папка» и «Переименовать»: поле с фокусом и открытой клавиатурой сразу, кнопка подтверждения неактивна при пустом или недопустимом имени, ошибка имени — под полем (`supportingText`), а не snackbar. При переименовании файла выделено имя без расширения.
- «Удалить»: заголовок «Удалить "IMG_2041.jpg"?» или «Удалить 5 объектов?», текст «Файлы будут удалены с сервера. Отменить нельзя.», кнопка «Удалить» цветом `error`.

**Отклик на действия.** После создания, переименования, перемещения, копирования, удаления — snackbar «Папка создана», «Перемещено: 3» и т. п. После загрузки — snackbar «Загружено: 7» и обновление списка, если пользователь в той же папке.

**Пустое и ошибочное состояние** — компоненты из 2.4.

**Вид сеткой** — **расширяет SPEC**. Переключатель «Список / Сетка» в шапке; сетка с превью 3 колонки для папок с фото. Делать только после согласия.

### 2.6 Выбор папки

- Шапка: «×» (отмена), заголовок по действию: «Куда переместить», «Куда копировать», «Папка для альбома "Camera"». Под заголовком — текущий путь мелко.
- Показываются только папки; файлы скрыты (либо показаны серыми и не нажимаются).
- Хлебные крошки как на экране файлов.
- Снизу закреплённая панель: «Новая папка» (`OutlinedButton`) и «Переместить сюда» / «Копировать сюда» / «Выбрать эту папку» (`Button`). Для перемещения кнопка неактивна, если папка — та же, откуда перемещаем, или вложенная в перемещаемую.
- FAB и мультивыбора нет.

### 2.7 Экран «Подключение»

- Шапка: «Подключение»; при входе из файлов — стрелка «Назад».
- Над полями — иконка приложения 64 dp и строка «Укажите адрес WebDAV вашего роутера» (только при первом запуске).
- Поля: «Адрес» (placeholder `https://имя.keenetic.link/webdav/`, иконка `Link`), «Логин» (иконка `Person`, подсказка под полем «Учитывается регистр букв»), «Пароль» (иконка `Lock`, справа иконка-глаз `Visibility`/`VisibilityOff` вместо текстовой кнопки). `ImeAction.Next` между полями, `Done` на пароле запускает проверку.
- «Разрешить HTTP» — `Switch` строкой. Предупреждение о незашифрованном пароле — `Notice` предупреждения, **только когда переключатель включён** или адрес начинается с `http://`.
- Предупреждение о пробеле в пароле — `supportingText` под полем пароля.
- Кнопка «Проверить и сохранить» — `Button` на всю ширину внизу; во время проверки внутри кнопки `CircularProgressIndicator` 20 dp и текст «Проверка…», поля неактивны.
- Ошибка — `Notice` ошибки над кнопкой, коротко: заголовок («Неверный логин или пароль») и одна строка пояснения. Длинные тексты из `strings.xml` сократить: подсказку про регистр перенести в подпись поля логина, про блокировку роутера — оставить одной фразой.
- «Способ входа: Basic» и «Проверяется адрес» — в свёрнутом блоке «Подробности» под ошибкой, не в основном потоке.
- Успех: snackbar «Подключено» на экране файлов.
- «Проверить обновление» с этого экрана убрать в меню «⋮» экрана файлов. *SPEC 3.4 требует кнопку на экране подключения — либо оставить её там внизу экрана как `TextButton` «Версия 1.0.2 · Проверить обновление», либо поправить SPEC. Предпочтительно первое: снизу, мелко, вместе с номером версии.*

### 2.8 Экран «Синхронизация»

**Шапка:** «Синхронизация», действие «Синхронизировать сейчас» — `TextButton` с текстом или иконка `CloudSync` с подписью в tooltip. Во время синхронизации кнопка заменяется на «Отмена».

**Блок статуса** (сверху, карточка `surfaceContainer`):
- Нет ошибок, нечего выгружать: иконка `CloudDone`, «Всё выгружено», «Последняя проверка: сегодня в 14:03».
- Идёт выгрузка: «Выгружено 12 из 87», прогресс-бар, имя текущего файла и процент, кнопка «Отмена».
- Ожидание условий: «Ждём Wi-Fi» / «Ждём зарядку» с иконкой.
- Ошибка: иконка `ErrorOutline`, текст, кнопка «Повторить».

**Предупреждения** — `Notice` под статусом, по важности: нет доступа к медиа (ошибка, кнопка «Открыть настройки») → частичный доступ (предупреждение) → оптимизация батареи (предупреждение, кнопка «Отключить», можно закрыть) → геометки (информация, можно закрыть). Не больше двух сразу: остальные скрыть под «Ещё предупреждения: 2».

**Карточка пары** (`ElevatedCard` или `OutlinedCard`, `shapes.medium`):
- Шапка карточки: превью последнего фото альбома 48 dp, имя альбома (`titleMedium`), под ним путь на сервере с иконкой `Folder`; справа общий `Switch` «включена».
- Строка статуса пары: «Ожидают: 14 · Последняя: 12.11 14:03» или ошибка с кнопкой «Повторить».
- Параметры — `FilterChip` в одну-две строки: «Фото», «Видео», «Только Wi-Fi», «При зарядке», «Только новые». Вместо шести переключателей подряд.
- «⋮» в шапке карточки: «Изменить папку», «Убрать альбом».
- «Убрать альбом» — диалог подтверждения: «Перестать синхронизировать "Camera"? Файлы на сервере останутся.»
- Выключенная пара — карточка приглушена (контент с `alpha` через `LocalContentColor`/disabled-цвета), чипы неактивны.

**Добавление пары** — `ExtendedFloatingActionButton` «Добавить альбом». Шаги:
1. Нижний лист «Выберите альбом»: строки с превью последнего фото 56 dp, именем альбома и числом файлов. Уже добавленные альбомы отмечены и неактивны.
2. Выбор папки сервера (2.6) с заголовком «Папка для альбома "Camera"».
3. Нижний лист «Что выгружать»: чипы «Фото», «Видео», «Только Wi-Fi», «При зарядке», переключатель «Только новые с сегодня» с подсказкой «Иначе выгрузится весь альбом: 2 341 файл». Кнопка «Готово».

Разрешения запрашивать перед шагом 1 с пояснением в нижнем листе («Чтобы выгружать фото, приложению нужен доступ к галерее»), а не сразу системным диалогом.

### 2.9 Просмотр фото

- Фон — чёрный в любой теме, системные панели светлые иконки.
- Полноэкранный режим: одиночное нажатие прячет и показывает шапку и нижнюю панель (и системные панели через `WindowInsetsControllerCompat`). Шапка и панель — полупрозрачный чёрный фон (`scrim`), анимация появления 200 мс.
- Шапка: «Назад», имя файла, справа «3 из 20».
- Нижняя панель: «Скачать», «Сведения» (нижний лист: размер, дата, путь), «Удалить» (с подтверждением; после удаления — следующее фото или выход, если фото было последним).
- Пока фото грузится — `CircularProgressIndicator` по центру поверх размытого превью из кэша списка, если оно есть. Ошибка загрузки — иконка `BrokenImage` и «Повторить».
- Масштаб и двойное нажатие — как сейчас. При масштабе > 1 свайп листает только у края изображения.
- Смахивание вниз закрывает просмотр — **по желанию**, если не мешает панорамированию.

### 2.10 Видео

- Полноэкранный чёрный экран без Scaffold-шапки; имя файла и «Назад» — в оверлее, который прячется вместе с контролами плеера.
- Кнопка «На весь экран» переключает ландшафт; при повороте телефона видео заполняет экран.
- Пока буферизуется — индикатор плеера (`setShowBuffering(SHOW_BUFFERING_ALWAYS)`).
- Ошибка воспроизведения — понятный текст («Не удалось воспроизвести видео. Формат не поддерживается или сервер не отдаёт файл по частям») и кнопки «Повторить», «Скачать».
- Пауза при уходе в фон — как сейчас.

### 2.11 Обновление приложения

- Диалог короче: заголовок «Доступна версия 1.0.3» или «У вас последняя версия», одна строка текста.
- Прогресс: «12,4 из 18,0 МБ · 69%» и линейный индикатор.
- Если нужно разрешение на установку — отдельный шаг с текстом «Разрешите установку из FamilyCloud» и кнопкой «Открыть настройки»; после возврата кнопка «Установить».

### 2.12 Уведомления

- Канал «Выгрузка», важность низкая (уже так).
- Заголовок: «Выгрузка в FamilyCloud»; текст: «12 из 87 · IMG_2041.jpg»; прогресс текущего файла; действие «Отмена» с иконкой.
- По окончании ручной синхронизации — короткое уведомление «Выгружено 87 файлов» (самоудаляющееся через 5 секунд, `setTimeoutAfter`), ошибка — «Выгрузка остановлена: нет места на сервере» с действием «Открыть».
- Нажатие по уведомлению открывает экран синхронизации (или файлов для загрузок).

### 2.13 Тексты

- Короткие фразы, без технических слов в основном потоке: «Корень» → иконка дома, «PROPFIND», «Basic», «Digest» — только в «Подробностях».
- Кнопки — глаголом: «Создать», «Переместить сюда», «Удалить», «Повторить».
- Числа — с учётом множественного числа через `plurals`: «1 файл», «3 файла», «7 файлов».
- Размеры — «2,4 МБ» с запятой по локали (`%1$.1f` уже учитывает локаль, проверить), до 1 КБ — «512 Б».
- Даты: сегодня — «14:03», вчера — «Вчера, 14:03», этот год — «12 нояб., 14:03», раньше — «12.11.2025».
- Удалить неиспользуемые строки (`files_title`, `permissions`, `loading`), если они не понадобятся по этому ТЗ.

### 2.14 Доступность

- У всех иконок-кнопок — `contentDescription`, у декоративных — `null`.
- Зоны нажатия не меньше 48 dp.
- Строка списка — одна сущность для TalkBack: «IMG_2041.jpg, изображение, 2,4 МБ, 12 ноября». Состояние выделения — `selected` в семантике.
- Масштаб шрифта 200%: имена переносятся или обрезаются многоточием, кнопки не наезжают друг на друга, шапка не ломается.
- Контраст текста — не ниже 4.5:1 (токены M3 это дают; не использовать `alpha` для обычного текста).
- Тёмная тема проверяется на каждом экране.

### 2.15 Поворот и большие экраны

- Поворот — без потери состояния (уже так), диалоги и нижние листы сохраняются.
- На ширине ≥ 600 dp (планшет, раскладушка): `NavigationRail` вместо нижней панели, список файлов ограничен по ширине 840 dp по центру, просмотр фото — на весь экран. Двухпанельный режим не делать.

### 2.16 Код

- Разнести `Screens.kt` по пакетам из `SPEC.md` раздел 5: `ui/browser/`, `ui/sync/`, `ui/settings/`, `ui/viewer/`, общие компоненты — `ui/components/`, тема — `ui/theme/`.
- Каждый экран: `XxxRoute` (берёт ViewModel, собирает состояние через `collectAsStateWithLifecycle`) и `XxxScreen` (без ViewModel, принимает состояние и лямбды) — чтобы были `@Preview`.
- `@Preview` для каждого экрана в светлой и тёмной теме и для состояний: загрузка, пусто, ошибка, список, мультивыбор.
- Интенты (`startActivity`, настройки) — из Route, не из глубины экрана.

**Критерии приёмки дизайна**

1. Жест «Назад» нигде не закрывает приложение неожиданно и не теряет выделение без намерения.
2. На каждом экране есть видимые состояния загрузки, пустоты и ошибки.
3. Ни одного захардкоженного цвета и размера шрифта в экранах (`Color(0x` и `.sp` встречаются только в `ui/theme/`).
4. Все экраны выглядят корректно в светлой и тёмной теме на Android 8–11 (своя схема) и 12+ (Dynamic Color).
5. Шрифт 200%: ничего не обрезано без многоточия, ничего не перекрывается.
6. Удаление на сервере и удаление пары всегда с подтверждением.
7. Идущая выгрузка видна в приложении, а не только в уведомлении.
